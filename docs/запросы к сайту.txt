Регистрация платежа:
POST с json на адрес https://kazna.shop/src/api/bot_steam_register.php
{
  "bot_token": "...",
  "invoice_id": "b123",
  "agent_transaction_id": "17701843151184357",
  "payment_id": "uuid-...",
  "user_id": 123456789,
  "steam_account": "mysteamlogin",
  "steam_amount": 500,
  "payment_amount": 515
}

Возвращает:
{ "success": true }

Важно: invoice_id должен начинаться с префикса "b" (например: b123)

//   409 { "error": "Promo code limit exceeded" } — лимит использований исчерпан
//   500 { "error": "..." }                       — ошибка сервера / БД
